# v3: нацдух чисток + ветка «Внутренние дела»

Изменения к v2:
- чистки больше не навешивают ванильные духи по одному, а качают один временный нацдух `SOV_purge_spirit_1..3`;
- ветка политики переделана в «Внутренние дела» — 33 фокуса по реальной истории 1938–1953;
- капстоуны больше не висят на датах в пустоте: «Наследие» и «Вождь всех времён» закрывают именно эту ветку.

Промка (18), военка (16), пропаганда и патчи ванильных механик — без изменений, см. v2.

## 1. Нацдух чисток

Три идеи, одна цепочка. Ставится первым фокусом-чисткой, каждый следующий поднимает уровень и обновляет таймер, последний оставляет таймер догорать.

| Уровень | Название | Эффекты |
|---|---|---|
| 1 | Чистки в армии I | −5% армейский опыт, −5% организация, +5% политвласть, +3% стабильность |
| 2 | Чистки в армии II | −10% армейский опыт, −10% организация, −5% скорость доктрин, +10% политвласть, +5% стоимость советников |
| 3 | Чистки в армии III | −15% армейский опыт, −15% организация, −10% скорость доктрин, +10% стабильность, +15% политвласть, +10% стоимость советников |

Логика: террор даёт политическую управляемость и очки, но выедает армию. Это осознанный обмен, а не чистый минус.

**Таймер.** Каждый уровень вешается через `add_timed_idea` на 540 дней (1.5 года). Новая чистка снимает текущий уровень и ставит следующий с новым таймером. После последней чистки таймер догорает, и дух исчезает сам. «Обезглавить змею» и «Реабилитация» снимают его досрочно.

Скриптовый эффект (файл `common/scripted_effects/zz_sov_purge.txt`):

```txt
SOV_purge_escalate_effect = {
    if = { limit = { has_idea = SOV_purge_spirit_1 } remove_ideas = SOV_purge_spirit_1 }
    else_if = { limit = { has_idea = SOV_purge_spirit_2 } remove_ideas = SOV_purge_spirit_2 }
    else_if = { limit = { has_idea = SOV_purge_spirit_3 } remove_ideas = SOV_purge_spirit_3 }

    add_to_variable = { SOV_purge_level = 1 }
    clamp_variable = { var = SOV_purge_level min = 1 max = 3 }

    if = { limit = { check_variable = { SOV_purge_level = 1 } }
        add_timed_idea = { idea = SOV_purge_spirit_1 days = 540 } }
    if = { limit = { check_variable = { SOV_purge_level = 2 } }
        add_timed_idea = { idea = SOV_purge_spirit_2 days = 540 } }
    if = { limit = { check_variable = { SOV_purge_level = 3 } }
        add_timed_idea = { idea = SOV_purge_spirit_3 days = 540 } }
}
```

Идеи лежат в `common/ideas/zz_sov_purge.txt`, категория `country`, `allowed = { always = no }`, `removal_cost = -1`, иконка — ванильная `SOV_purged_junior_army_officers`, чтобы не рисовать новую.

Кто качает дух:

| Источник | Уровень |
|---|---|
| Зиновьевский троцкистский центр (ванильный) | 1 |
| Антисоветский троцкистский центр (ванильный) | 2 |
| Заговор военных (ванильный) | 3 |
| Блок правых и троцкистов (ванильный) | 3, таймер обновляется |
| Ленинградское дело (новый) | +1 |
| Дело врачей (новый) | +1 |
| Обезглавить змею (ванильный) | снимает полностью |
| Реабилитация (новый) | снимает полностью |

## 3. Что учесть

- Даты в `available` — не блокируют взятие, а просто открывают фокус; если игрок дошёл раньше, он ждёт.
- Часть фокусов (патриаршество, краткий курс) висит на 1943/1938 — они открываются не от «Отца народов», а от «Культа личности», иначе историческая дата не имеет смысла. Значит, у ветки два входа: ранний (культ) и поздний (1945).
- Депортации народов сознательно не включаю: тема тяжёлая, а механики HOI4 её всё равно не отразят, кроме минуса к комплаенсу. Если нужна — скажи, сделаю отдельным фокусом с честным дебаффом.
- Чистки теперь ещё и политический ресурс: дух даёт политвласть и стабильность ценой армии. Баланс этого обмена — главное, что придётся крутить.

## 4. Проверка

- `add_timed_idea` в стране-скоупе валиден (в ваниле так делают Афганистан и другие).
- `clamp_variable`, `check_variable` — ванильные эффекты/триггеры.
- Валидатор модификаторов: `local_resources_factor`, `compliance_gain`, `operative_slot`, `army_defence_factor` — все есть в ваниле (проверено по файлам).
